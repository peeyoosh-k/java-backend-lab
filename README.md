## Why this repo exists

I'd forgotten a lot of what I learned earlier, so I decided to rebuild my Java foundation in a structured way instead of jumping between tutorials. Writing code every day, with notes next to it, is the only method that has worked for me.

What I want from this repo:

- A clean reference I can come back to before interviews
- Proof of consistent practice, not just a few big commits
- A solid base before moving on to Spring Boot and databases

## Repository structure

| Folder | What it covers |
|---|---|
| `00-setup` | JDK, IntelliJ IDEA, Git, running Java from the terminal |
| `01-java-basics` | Syntax, data types, control flow, arrays, strings, methods |
| `02-oop` | Classes, inheritance, polymorphism, abstraction, interfaces, SOLID |
| `03-exceptions-and-io` | Exception handling, file I/O, NIO, serialization |
| `04-collections-and-generics` | List, Set, Map, Queue, generics, HashMap internals |
| `05-modern-java` | Lambdas, Streams, Optional, records, Java 21 features |
| `06-multithreading-and-concurrency` | Threads, synchronization, executors, CompletableFuture |
| `07-jvm-internals` | Memory model, garbage collection, class loading |
| `08-advanced-java` | Reflection, annotations, sockets, HttpClient |
| `09-dsa-in-java` | Data structures and algorithms, LeetCode solutions |
| `10-design-patterns` | Creational, structural and behavioral patterns |
| `11-build-tools-and-testing` | Maven, Gradle, JUnit 5, Mockito |
| `projects` | Core Java projects built from what I've learned |
| `interview-prep` | Question banks and revision notes |
| `notes` | Cheat sheets and mistakes I've learned from |

Each topic folder is numbered and contains the programs for that topic, so you can follow the learning order from top to bottom.

## How to run the programs

You need **JDK 17 or newer** (I use JDK 21 Temurin).

Run a single file from the terminal:

```bash
javac Example.java
java Example
```

Or open the whole repository in **IntelliJ IDEA** and use the green Run button next to `main`.
